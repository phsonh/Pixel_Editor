# Pixel Editor 8.4

一个面向像素素材、纹理图集和 JSON 切片数据的 Windows 编辑器，使用 Python 与 PyQt5 编写。

## 快速上手

1. **导入素材**：选择“文件 → 导入图片”，按 `Ctrl+O`，或把 PNG、JPG/JPEG、BMP 直接拖进窗口。已有选区时，首张图片会以选区左下角为锚点放置；同时导入多张图片时会从该位置开始无间隔向右排列。
2. **查看和移动画布**：滚动滚轮会以鼠标所在位置为中心缩放；按住中键拖动可平移画布。右下角状态栏持续显示鼠标位置和当前缩放值。
3. **建立选区**：按 `S` 切换到选择工具，在画布上拖出矩形。右侧面板会固定显示该选区的四角坐标、宽度、高度和单像素 ARGB；这些值不会随着鼠标移动而变化。
4. **调整选区**：拖动选区内部可移动像素，拖动边缘或角点可改变范围。移动步长按拖动当下的实时缩放计算，因此拖动过程中改变缩放后会立即使用新的对齐步长。
5. **处理选区**：在选区内单击右键，可复制、剪切、粘贴、旋转、翻转、缩放、叠加颜色或删除。缩放窗口可选择采样方式、缩放中心、8 位小数倍率或目标宽高；叠加颜色窗口可预览颜色与混合模式，确认后直接修改原选区。
6. **创建 JSON 切片**：先建立选区，再按 `Ctrl+J`。填写名称，并按需修改 `center_dx`、`center_dy`、`hscale`、`vscale` 和 `mipmap`；按 `Enter` 保存。中心偏移微调框的步进为 `0.5 px`。
7. **批量选择切片**：点击切片正文进行单选；点击前方复选框可以追加或取消多个切片；点击列表空白处清空选择；`Ctrl+A` 全选。
8. **同步移动像素和切片**：按住 `Ctrl` 拖动选区。选区完整包含的 JSON 切片会和像素一起移动并更新坐标；只要存在仅被部分覆盖的切片，本次同步移动就会被拒绝。
9. **按上下文删除**：画布获得焦点时，`Del` 只删除选区像素；JSON 切片列表获得焦点时，`Del` 只删除所选切片数据；`Ctrl+Del` 删除选区像素及其中完整包含的切片，并可通过一次撤销恢复。
10. **导出结果**：按 `Ctrl+S` 导出 PNG，按 `Ctrl+Shift+S` 导出 JSON。导出 JSON 时会为旧切片自动补齐全部元数据字段。

## 主要功能

- 画笔、橡皮、矩形选择和顶点标记工具。
- 可扩展画布、像素网格、鼠标位置状态、滚轮缩放和画布平移。
- 支持 PNG、JPG/JPEG、BMP 导入；JPG/BMP 会自动转换为带 Alpha 通道的图像数据。
- 支持图片和 JSON 拖入窗口，也支持把文件拖到 EXE 上通过命令行参数打开。
- 选区移动、边界缩放、复制、剪切、粘贴、旋转 90°、水平/垂直翻转。
- 选区缩放支持双线性/临近点采样、五种缩放中心、8 位小数倍率、目标宽高和宽高比锁定。
- 选区颜色叠加带实时预览，支持正常、覆盖、正片叠底、滤色、叠加、柔光、强光、变暗、变亮、颜色减淡、颜色加深、差值和相加模式。
- 右侧面板显示选区四角坐标、宽高、单像素 ARGB，以及画笔颜色盘。
- 支持左上角原点/Y 向下和左下角原点/Y 向上两种坐标系。
- 撤销与重做。

## JSON 切片

编辑器可以创建、修改、复制、粘贴、批量选择、导入、合并和导出 JSON 切片。导入多个 JSON 时会合并数据；遇到同名切片时会列出重名项，并询问是否自动添加 `_2` 等后缀。

每个切片导出以下字段：

```json
{
  "player_idle": {
    "x": 0,
    "y": 0,
    "w": 32,
    "h": 32,
    "center_dx": 0,
    "center_dy": 0,
    "hscale": 1,
    "vscale": 1,
    "mipmap": false
  }
}
```

- `x`、`y`、`w`、`h`：切片位置和尺寸。
- `center_dx`、`center_dy`：旋转/缩放中心相对切片几何中心的偏移，编辑步进为 `0.5 px`。
- `hscale`、`vscale`：外部使用的水平/垂直缩放值；编辑器只保存和编辑，不作用于画布图像。
- `mipmap`：外部使用的布尔标记。

旧 JSON 缺少可选字段时会采用默认值；再次导出时会补齐全部字段。画布缩放足够大时会显示切片名称和旋转/缩放中心点。

### 切片列表选择

- 点击切片正文：单选该切片，再次点击不会取消。
- 点击切片前的复选框：追加或取消切片，可连续多选，不需要按住修饰键。
- 点击列表空白处：清空全部选择。
- `Ctrl+A`：全选切片。

### 切片与像素同步移动

使用选择工具拖动选区时按住 `Ctrl`，如果选区完整包含一个或多个 JSON 切片，切片坐标会随像素同步移动。只要有相交切片未被完整包含，本次同步移动就会被拒绝。

选区拖动步长会根据当前实时画布缩放计算；拖动过程中缩放画布后，会立即改用新的对齐步长。

## 基本操作

### 鼠标

- 滚轮：以鼠标位置为中心缩放画布。
- 中键拖动：平移画布。
- 未建立选区时右键拖动：平移画布。
- 选择工具拖动空白区域：建立选区。
- 拖动选区内部：移动选区像素。
- 拖动选区边缘/角点：调整选区大小。
- 选区内右键：打开复制、剪切、粘贴、旋转、翻转、缩放、叠加颜色和删除菜单。

### 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `P` / `E` / `S` / `V` | 画笔 / 橡皮 / 选择 / 顶点工具 |
| `Ctrl+O` | 导入图片 |
| `Ctrl+J` | 新建 JSON 切片 |
| `Ctrl+Shift+J` | 导入 JSON |
| `Ctrl+S` | 导出 PNG |
| `Ctrl+Shift+S` | 导出 JSON |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴选区 |
| `Ctrl+R` / `Ctrl+Shift+R` | 顺时针 / 逆时针旋转 90° |
| `Ctrl+Shift+C` | 裁剪选区并另存 |
| `F2` | 修改当前 JSON 切片 |
| `Enter` | 保存正在新建或修改的 JSON 切片 |
| `Del`（画布焦点） | 只删除选区内像素 |
| `Del`（切片列表焦点） | 只删除勾选/选中的 JSON 切片数据 |
| `Ctrl+Del` | 删除选区内像素，并删除选区完整包含的 JSON 切片 |

`Ctrl+Del` 是一次撤销操作；部分相交但未被完整包含的切片数据不会被删除。

## 文件与默认保存位置

- 图片导出格式为 PNG。
- 打开单个图片后，默认 PNG/JSON 文件名沿用图片名称。
- 打开现有 JSON 后，默认 JSON 文件名沿用原文件名。
- 默认保存目录只记录最初打开文件所在的目录，后续另存位置不会覆盖该记录。

## 项目结构

```text
Pixel_Editor/
├─ assets/       图标等资源
├─ src/          Python 源码
├─ tools/        构建脚本
└─ build/        本地构建产物（Git 已忽略）
```

## 运行源码

安装运行依赖：

```powershell
pip install PyQt5
python src/main.py
```

也可以传入一个或多个支持的文件：

```powershell
python src/main.py image.png sprites.json
```

## 构建 Windows EXE

安装构建依赖：

```powershell
pip install PyQt5 pyinstaller
```

执行项目提供的构建脚本：

```powershell
powershell -ExecutionPolicy Bypass -File tools/build.ps1
```

构建脚本会使用 `assets/pixel_editor_logo.ico` 作为多尺寸 EXE 图标，并把 PNG 图标打包为运行时窗口图标。默认产物：

```text
build/pixel8.4像素编辑器.exe
```

如需指定版本名：

```powershell
powershell -ExecutionPolicy Bypass -File tools/build.ps1 -Version 8.4
```
